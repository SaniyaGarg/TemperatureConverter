
# Travel & Tourism Landing Page

## About the Project
This is a Travel and Tourism Landing Page created as part of the Oasis Infobyte Web Development Internship (OIBSIP).

The website is designed to showcase travel destinations and encourage users to explore different places.

## Features
- Attractive homepage design
- Navigation bar
- Travel destination section
- Beautiful images
- Explore and booking buttons
- Responsive layout

## Technologies Used
- HTML5
- CSS3

## Project Structure
- index.html
- style.css
- images/

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
