
# Temperature Converter Website

## About the Project
This is a simple and interactive Temperature Converter Website built using HTML, CSS, and JavaScript.

It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

## Features
- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Simple and user-friendly interface.
- Input validation for empty and invalid values.
- Handles absolute zero temperature validation.
- Reset button to clear the input and results.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use
1. Enter a temperature value.
2. Select the input unit (Celsius, Fahrenheit, or Kelvin).
3. Click on the Convert Temperature button.
4. View the converted results in all three units.
5. Click Reset to clear the values.

## Conversion Formulas

- Celsius to Fahrenheit: (C × 9/5) + 32
- Fahrenheit to Celsius: (F - 32) × 5/9
- Celsius to Kelvin: C + 273.15
- Kelvin to Celsius: K - 273.15
